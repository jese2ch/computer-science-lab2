Лабораторная работа №2 — Яндекс Карты

Вариант 3

Готовый комплект лабораторной работы по исследованию HTTP-взаимодействия веб-приложения Яндекс Карты.

Файлы

- `report.md` — полный отчёт;
- `interaction.drawio` — редактируемая диаграмма;
- `interaction.png` — PNG диаграммы;
- `interaction.svg` — векторная версия диаграммы;
- `images/README.txt` — пояснение по исходным скриншотам.

Исследованные endpoints

- `GET /maps/api/search`
- `GET /maps/api/taxi/getRoute`

Реальные значения cookies, `csrfToken` и `sessionId` намеренно не включены в репозиторий.
